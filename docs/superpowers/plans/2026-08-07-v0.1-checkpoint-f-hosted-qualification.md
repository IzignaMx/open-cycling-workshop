# V0.1 Checkpoint F Hosted Qualification Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make hosted V0.1 qualification exercise the production PWA artifact and emit self-identifying evidence while preserving honest blockers in restricted local environments.

**Architecture:** Keep `scripts/ci/verify_v01.py` as the canonical cross-layer evidence collector. GitHub Actions installs full dependencies, builds the production PWA, runs Playwright against `vite preview`, executes the verifier, and uploads its JSON evidence. Local execution remains useful by reporting unavailable toolchains as blockers rather than false failures.

**Tech Stack:** Python 3.13, uv, GitHub Actions, pnpm 11.17, Vite 8, vite-plugin-pwa, Playwright, axe, FastAPI, PostgreSQL 18.4.

## Global Constraints

- Preserve `AGPL-3.0-only` and DCO policy.
- Preserve Offline First and Local First behavior.
- Do not mark environment-dependent gates complete without runtime evidence.
- Hosted browser E2E must use the production PWA build rather than the Vite development server.
- Qualification evidence must identify the exact commit and runtime environment.
