# Consumed diagnostic source archive

**Historical, failed and consumed. Not executable qualification instructions.**

These inert patches preserve all original code, documentation, tests and workflow
changes from PR #51 and PR #56, including their then-current pending-state wording.
Neither patch is applied to active source. Do not apply a patch, revive a workflow,
repeat a specimen, rename a trigger or increase a budget from this archive.
The original branches, commits, PR descriptions and evidence remain preserved.

Each patch is the exact `git diff --binary --full-index BASE HEAD --` output.
[manifest.json](manifest.json) records the original base/head/tree, every changed
head blob, byte length and SHA-256. This allows reconstruction against the named
base in an isolated Git index without executing any code. The archive falls under
the repository's AGPL-3.0-only REUSE annotation; original attribution/DCO remains
in the referenced commit history.
