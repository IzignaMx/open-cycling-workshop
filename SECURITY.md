# Security Policy

## Supported versions

Until V1.0, only the latest development line is supported for security fixes. Stable support windows will be published with the first production release.

## Reporting a vulnerability

Do not open public issues for suspected vulnerabilities that could expose users or data. Use the repository's private security-advisory mechanism when available, or contact the maintainers privately.

Include, when possible:

- affected version or commit
- threat scenario
- reproduction steps
- expected and observed behavior
- impact assessment
- suggested mitigation if known

The project follows coordinated disclosure and will preserve reporter credit unless anonymity is requested.
